# Agent 评测系统原型

高保真 HTML 原型，用于演示面向多 Agent 的评测系统。

## 支持的 Agent

- 招聘 Agent
- 外卖门店诊断 Agent
- AI 生图 Agent
- 智能客服 Agent

## 核心功能

- Agent 评分总览
- 单 Agent 专项评分详情
- 招聘 / 门店诊断 / AI 生图 / 智能客服的独立评分维度
- 数据集管理与版本冻结
- 用例库与用例评分规则
- 评分器注册表与管理
- LLM 评分、过程指标、过程评分、人工复核
- 评测任务列表、新增、编辑、删除
- 报告、基线与发布门禁
- Agent 与环境配置

## 预览

直接打开 `index.html` 即可预览，无需安装依赖。
